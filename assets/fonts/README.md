# Fonts

Self-hosted latin subsets, served as `woff2` with `font-display: swap`.

| File | Family | Styles used |
|---|---|---|
| `fraunces-roman.woff2` | Fraunces (variable, opsz 9–144) | 400, 600 |
| `fraunces-italic.woff2` | Fraunces Italic | 400 |
| `figtree.woff2` | Figtree (variable) | 400, 600 |

(<https://openfontlicense.org>). Source: Google Fonts.
